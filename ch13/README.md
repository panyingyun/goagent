# 课时13:模型路由与成本优化

> 目标:让 Agent 在"贵但聪明"和"便宜但快"之间自动取舍,并缓存省钱。

## 本课时学什么

1. **启发式路由**:复杂任务(分析/写代码/长文本)用 `deepseek-v4-pro`,
   简单任务用 `deepseek-v4-flash`;
2. **预算控制**:每日花费超过一半就强制降级到便宜模型;
3. **响应缓存**:相同问题 10 分钟内直接返回缓存,不花一分钱。

## 运行

```powershell
cd E:\codex\project001\goagent\ch13
go run . "1+1 等于多少?"
go run . "帮我分析 Go 和 Rust 的优缺点"
```

同一个问题跑两次,第二次会看到"缓存命中"。

## 练习

1. 把 `DailyBudget` 改成 0.0001,观察复杂问题也被降级;
2. 给 `isComplex` 加一个你自己的关键词;
3. 思考:缓存适合所有问题吗?(提示:涉及时效性的问题不该缓存。)
