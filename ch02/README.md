# 课时2:提示词工程

> 目标:掌握三个最实用的提示词技巧,让同一个模型表现更好、更可控。

## 三个技巧

1. **系统提示词**:给模型"角色 + 规则",约束回答方式;
2. **few-shot**:给 2~3 个例子,模型照葫芦画瓢,比空口要求更稳;
3. **结构化输出**:要求 JSON,再用代码解析 + 校验,方便程序消费。

## 运行

```powershell
cd E:\codex\project001\goagent\ch02
go run . "这家店的服务很一般"
go run . "太棒了,满分好评!"
```

三种技巧会依次跑同一句话,对比输出差异。

## 关键认知

- 提示词是"给模型的编程接口",好的提示词能把模型上限发挥出来;
- 结构化输出一定要**校验**(模型偶尔会漏字段、写错枚举值),不能直接信任;
- 技巧2 和技巧3 都可以组合使用,课时11 的任务规划就依赖 JSON 输出。

## 练习

1. 给 few-shot 加一个"英文评论"的例子,看模型能不能举一反三;
2. 让模型输出"价格区间",试几个不在枚举里的值,观察校验兜底;
3. 想想:为什么生产环境要求结构化输出,而不是让程序解析自然语言?
